# Nじゃあるまいし＜否定性原因＞ <Badge type="danger" text="N1" />

* 意义：表示否定性的原因、理由，主句一般为说话人的判断、反问、祈使、责备、推测等。
* 接续：名词＋じゃ（では）あるまいし
* 译文：又不是……，（所以）

::: info :books: 例句

1. <grammer-content sentence='アニメ**じゃあるまいし**、[大金持/おおがねも]ちでかわいくて[性格/せいかく]もいい[女/おんな]の[子/こ]がいるわけがない。' trans='又不是动画，不可能有又有钱又可爱性格又好的女孩子。' />
2. <grammer-content sentence='[子供/こども]**じゃあるまいし**、そんなことで[泣/な]くな。' trans='又不是孩子，别因为那种事哭。' />
3. <grammer-content sentence='[外国人/がいこくじん]**じゃあるまいし**、[箸/はし]の[使/つか]い[方/かた]くらい[知/し]ってるよ。' trans='又不是外国人，筷子的用法还是知道的。' />
4. <grammer-content sentence='[夏/なつ]**じゃあるまいし**、そんなに[暑/あつ]くないよ。' trans='又不是夏天，没那么热。' />
5. <grammer-content sentence='[子供/こども]**じゃあるまいし**、[自分/じぶん]のことは[自分/じぶん]で[決め/きめ]てください。' trans='又不是小孩子，自己的事请自己决定。' />
6. <grammer-content sentence='[神様/かみさま]**じゃあるまいし**、[事故/じこ]を[予知/よち]して[防ぐ/ふせぐ]なんて[無理/むり]な[話/はなし]だ。' trans='又不是神仙，哪能预知事故并加以防范。' />
7. <grammer-content sentence='コンピューター**ではあるまいし**、そんなにたくさん[頭/あたま]に[入/はい]らないよ。' trans='脑袋又不是电脑，哪记得住那么多啊。' />

:::

## 相关表达「まい」

<grammer-content sentence='「あるまい」是「ある」接「まい」的形式。「まい」还可接其他动词，表示否定意志或否定推测，多见于书面语或较郑重的表达。' />

<grammer-content sentence='五段动词用辞典形＋まい。一段动词可以用辞典形＋まい，也可以去掉「る」再接「まい」。「する」常见「するまい／すまい」。' />

::: info :books: 例句

1. <grammer-content sentence='[今回/こんかい]の[休み/やすみ]は**[帰る/かえる]まい**。' trans='这次放假，我打定主意不回去了。' />
2. <grammer-content sentence='[明日/あした]は[雨/あめ]が**[降る/ふる]まい**。' trans='明天大概不会下雨。' />

:::
