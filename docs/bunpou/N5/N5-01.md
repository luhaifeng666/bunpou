# Vなさい＜命令・敬体＞ <Badge type="info" text="N5" />

* <grammer-content sentence='意义：表示要求或命令，语气通常比简体命令形缓和。' />
* 接续：动词的第一连用形＋なさい（勉強する⇒勉強しなさい／勉強なさい）
* 译文：（请）……

::: tip :bookmark: 说明

<grammer-content sentence='「Vなさい」常见于大人对孩子、老师对学生、上级对下级等场合。对身份相当的人使用时，可能显得在发号施令。' />

<grammer-content sentence='也有「お／ご～なさい」这样的形式。「おやすみなさい」「ごめんなさい」已经成为使用场合相对固定的寒暄语。' />

<grammer-content sentence='在家人等亲近的人之间，可以把「Vなさい」随意地说成「Vな」。动词第一连用形加「な」是要求，如「[起/お]きな」。辞典形加「な」是禁止，如「[起/お]きるな」。' />

:::

::: info :books: 例句

1. <grammer-content sentence='[美咲/みさき]は[試験/しけん]の[前/まえ]になるといつも[弱気/よわき]になるわね。しっかり**しなさい**（しっかりなさい）。' trans='美咲考试之前总是变得胆小。要振作起来！' />
2. <grammer-content sentence='[早く/はやく][学校/がっこう]へ**行きなさい**。' trans='快点去学校。' />
3. <grammer-content sentence='もっとゆっくり**食べなさい**。' trans='再慢点吃。' />
4. <grammer-content sentence='[田中君/たなかくん]、ちょっと**来なさい**。' trans='田中君，过来一下。' />
5. <grammer-content sentence='もうすぐ[受験/じゅけん]なんだから、もっとしっかり**勉強しなさい**（勉強なさい）。' trans='马上就要考试了，要更认真地学习。' />
6. <grammer-content sentence='ゆっくりお**食べなさい**。' trans='请慢慢吃。' />
7. <grammer-content sentence='[薬/くすり]をお**飲みなさい**。' trans='请把药喝了。' />
8. <grammer-content sentence='この[本/ほん]をお**読みなさい**。' trans='请读这本书。' />
9. <grammer-content sentence='はやく**[起き/おき]な**（よ）。' trans='快起床吧。' />

:::
