# ～のみならず＜範囲＞ <Badge type="danger" text="N2" />

* 意义：表示事物存在的范围不限于此。
* 接续：名词（可加「である」）／动词、Ⅰ类形容词的连体形／Ⅱ类形容词词干＋である，再接「のみならず」。
* 译文：不仅……

::: info :books: 例句

1. <grammer-content sentence='この[本/ほん]は[子供/こども]**のみならず**、[大人/おとな]にも[人気/にんき]がある。' trans='这本书不仅孩子，大人也喜欢。' />
2. <grammer-content sentence='[彼/かれ]は[英語/えいご]**のみならず**、[日本語/にほんご]も[話/はな]せる。' trans='他不仅英语，日语也能说。' />
3. <grammer-content sentence='[経済的/けいざいてき]な[問題/もんだい]である**のみならず**、[社会的/しゃかいてき]な[問題/もんだい]でもある。' trans='这不仅是经济问题，也是社会问题。' />
4. <grammer-content sentence='[面白/おもしろ]い**のみならず**、[勉強/べんきょう]にもなる。' trans='不仅有趣，还能学到东西。' />
5. <grammer-content sentence='[日本国内/にほんこくない]**のみならず**[世界/せかい]から[愛さ/あいさ]れてきた[日本/にほん]のアニメは、[日本/にほん]を[代表/だいひょう]するカルチャーとなっている。' trans='日本动画不仅在日本国内，也在世界各地广受喜爱，已成为代表日本的文化之一。' />
6. <grammer-content sentence='[中小企業/ちゅうしょうきぎょう]**のみならず**、[大企業/だいきぎょう]でも[経費/けいひ]の[削減/さくげん]をしている。' trans='不只是中小企业，大企业也在削减开支。' />
7. <grammer-content sentence='プラスチックごみによる[汚染/おせん][問題/もんだい]は、[各国/かっこく]の[漁業/ぎょぎょう]や[観光/かんこう]に**[影響/えいきょう]を[与え/あたえ]るのみならず**、[人/ひと]の[健康/けんこう]にも[影響/えいきょう]を[及ぼ/およぼ]す。' trans='塑料垃圾造成的污染不仅影响各国的渔业和旅游业，也影响人体健康。' />
8. <grammer-content sentence='**[遅刻/ちこく]したのみならず**[教室/きょうしつ]も[間違っ/まちがっ]ていたため[受験/じゅけん]できなかった。' trans='不仅迟到了，还走错了教室，因此没能参加考试。' />
9. <grammer-content sentence='この[喫茶店/きっさてん]は、[紅茶/こうちゃ]が**おいしいのみならず**、ケーキも[人気/にんき]だ。' trans='这家咖啡馆不仅红茶好喝，蛋糕也很受欢迎。' />
10. <grammer-content sentence='[新しい/あたらしい]ライフスタイルは**[経済的/けいざいてき]であるのみならず**、[健康/けんこう]にもよい。' trans='新的生活方式不仅省钱，也有益健康。' />
11. <grammer-content sentence='このマンションは**[便利/べんり]であるのみならず**、[家賃/やちん]も[安い/やすい]。' trans='这套公寓不仅方便，房租也便宜。' />

:::
