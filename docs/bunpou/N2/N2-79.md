# ～はもとより～も＜累加＞ <Badge type="danger" text="N2" />

- 意义：举出理所当然的事物，再说明其他事物也具有同样的特征。
- 接续：名词＋はもとより；动词、形容词的连体形＋の＋はもとより。
- 译文：……自不必说，……也……；不仅……，而且……。

::: tip :bookmark: 说明

<grammer-content sentence='意思接近「～はもちろん～も」，语气较郑重，常用于书面语。后项常与「も」呼应，也可以接否定表达。' />

相关用法：[～はもちろん～も](N2-19.md)。

:::

::: info :books: 例句

1. <grammer-content sentence='[彼は/かれは]アメリカ**はもとより**[日本/にほん]にも[行った/いった]ことがない。' trans='他别说美国了，连日本也没有去过。' />
2. <grammer-content sentence='[数学/すうがく]**はもとより**、[化学/かがく]、[物理/ぶつり]も[得意/とくい]だ。' trans='数学自不必说，化学和物理也很擅长。' />
3. <grammer-content sentence='[最近/さいきん][仕事/しごと]が[多く/おおく]て、[土曜/どよう]**はもとより**、[日曜/にちよう]も[休ま/やすま]ずに[働い/はたらい]た。' trans='最近工作很多，不用说周六了，连周日也没有休息，一直在工作。' />
:::
