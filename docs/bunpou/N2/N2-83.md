# Vねばならない＜义务＞ <Badge type="danger" text="N2" />

- 意义：表示有必要或有义务进行某个动作。
- 接续：动词的ない形去掉「ない」＋ねばならない；「する」变为「せねばならない」。
- 译文：必须……；应该……。

::: tip :bookmark: 说明

<grammer-content sentence='意思与「Vなければならない」相同，常用于书面语或较郑重的表达。不是把完整的「Vない」直接接到「ねばならない」前。' />

<grammer-content sentence='例如「行かない→行かねばならない」「食べない→食べねばならない」「する→せねばならない」。' />

相关用法：[Vなくては／なければいけない・ならない](../N4/1-10-7.md)。

:::

::: info :books: 例句

1. <grammer-content sentence='[私たち/わたしたち]は、その[手段/しゅだん]を[探さ/さがさ]**ねばなりません**。' trans='我们必须寻找那个办法。' />
2. <grammer-content sentence='[私たち/わたしたち]も[平和/へいわ]のために[立ち上が/たちあが]ら**ねばならない**。' trans='我们也必须为了和平挺身而出。' />
3. <grammer-content sentence='[企業/きぎょう]を[変え/かえ]るためにはまず[社員/しゃいん]の[考え方/かんがえかた]を[変え/かえ]**ねばならない**。' trans='要改变企业，首先必须改变员工的观念。' />
4. <grammer-content sentence='[次の/つぎの][世代/せだい]のためによい[環境/かんきょう]を[作る/つくる]よう[努力/どりょく]せ**ねばならない**。' trans='必须为下一代努力创造良好的环境。' />
:::
