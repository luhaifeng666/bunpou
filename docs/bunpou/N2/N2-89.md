# ～ものの＜转折＞ <Badge type="danger" text="N2" />

- 意义：承认前项事实，同时说明后项结果没有如通常预期的那样发生。
- 接续：动词、形容词的连体形＋ものの；名词＋である＋ものの。
- 译文：虽然……但是……；尽管……却……。

::: tip :bookmark: 说明

<grammer-content sentence='较多用于书面语，后项通常描述实际状况、困难或与预期不同的结果，不用于直接向对方发出命令、请求或邀请。' />

:::

::: info :books: 例句

1. <grammer-content sentence='[咳/せき]はする**ものの**、[体調/たいちょう]は[戻っ/もどっ]てきている。' trans='虽然还会咳嗽，但身体状况已经逐渐恢复。' />
2. <grammer-content sentence='[中国/ちゅうごく]のアニメ[業界/ぎょうかい]は[著しい/いちじるしい][成長/せいちょう]を[見せ/みせ]ている**ものの**、[世界/せかい]の[最先端/さいせんたん]とはまだまだへだたりがある。' trans='中国动画业虽然发展迅速，但与世界最先进水平仍有相当大的差距。' />
3. <grammer-content sentence='[今日中/きょうじゅう]にこの[仕事/しごと]をやりますと[言った/いった]**ものの**、まだ[半分/はんぶん]もできていない。' trans='虽然说了今天之内会完成这项工作，但现在连一半都没做完。' />
4. <grammer-content sentence='[説明会/せつめいかい]に[行った/いった]**ものの**、[入社試験/にゅうしゃしけん]は[受け/うけ]なかった。' trans='虽然去了招聘说明会，但没有参加入职考试。' />
5. <grammer-content sentence='[適当/てきとう]な[運動/うんどう]と[食生活/しょくせいかつ]は[体/からだ]にいいとわかってはいる**ものの**、なかなか[実行/じっこう]できない。' trans='虽然知道适度运动和良好的饮食习惯对身体有益，却总是难以付诸实践。' />
:::
