# 疑问词＋～かというと＜设问＞ <Badge type="danger" text="N2" />

- 意义：先提出问题，再在后项给出自己的说明或回答。
- 接续：含有疑问词的简体疑问句＋かというと；名词、Ⅱ类形容词的疑问句可以使用「か／であるか」。
- 译文：要问……；要说……；说到……。

::: tip :bookmark: 说明

<grammer-content sentence='敬体形式有「かといいますと」。口语中也可以说「かっていうと」；相近表达有「かといえば」「かといったら」。' />

:::

::: info :books: 例句

1. <grammer-content sentence='[最後/さいご]の「[寂/じゃく]」はどういう[意味/いみ]である**かといいますと**、これはどんなときにでも[動じ/どうじ]ない[心/こころ]であるといえます。' trans='要问最后的“寂”是什么意思，可以说是无论何时都不为所动的内心。' />
2. <grammer-content sentence='この[小説/しょうせつ]はどこが[面白い/おもしろい]**かというと**、「[人間/にんげん]」についての[深い/ふかい][見方/みかた]だと[思い/おもい]ます。' trans='要问这部小说哪里有趣，我认为是它对“人”的深刻看法。' />
3. <grammer-content sentence='どんな[映画/えいが]**かというと**、[人間/にんげん]になりたいと[願う/ねがう]ロボットの[物語/ものがたり]です。' trans='要说这是什么样的电影，它讲的是一个想变成人类的机器人的故事。' />
4. <grammer-content sentence='なぜそんなに[自信/じしん]があった**かというと**、[誰/だれ]よりも[努力/どりょく]していると[思って/おもって]いるからです。' trans='要问为什么那么有自信，是因为我觉得自己比谁都努力。' />
:::
