# Nに代わって＜代替＞ <Badge type="danger" text="N2" />

- 意义：表示代替某人或某物完成后面的动作，或由另一事物接替其作用。
- 接续：名词＋に代わって／に代わり；修饰名词时用「Nに代わる＋名词」。
- 译文：代替……；取代……。

::: tip :bookmark: 说明

<grammer-content sentence='「に代わり」较多用于书面语。「N1に代わるN2」表示取代 N1 的 N2，注意修饰方向。' />

:::

::: info :books: 例句

1. <grammer-content sentence='[人間/にんげん]**に[代わり/かわり]**、ソフトだけでアニメを[創り/つくり][上げ/あげ]る[時代/じだい]がもう[目の前/めのまえ]に[来て/きて]いるのかもしれない。' trans='或许一个由软件代替人类、独立制作动画的时代已经近在眼前。' />
2. <grammer-content sentence='[弟/おとうと]は[兄/あに]**に[代わ/かわ]って**[家/いえ]を[継い/つい]だ。' trans='弟弟代替哥哥继承了家业。' />
3. <grammer-content sentence='[夏休/なつやす]み[中/ちゅう]、[忙しい/いそがしい][親/おや]**に[代わ/かわ]って**[毎日/まいにち][料理/りょうり]を[作っ/つくっ]ていた。' trans='暑假期间，我每天代替忙碌的父母做饭。' />
4. <grammer-content sentence='この[製品/せいひん]は、[今後/こんご]コンピューター**に[代わ/かわ]る**[新型機器/しんがたきき]として[注目/ちゅうもく]されている。' trans='这款产品作为将来可能取代计算机的新型设备而受到关注。' />
:::
