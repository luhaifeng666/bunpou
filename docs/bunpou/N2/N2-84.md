# ～とすれば＜条件＞ <Badge type="danger" text="N2" />

- 意义：假设前项事实成立，并据此作出后项的判断、推测或愿望表达。
- 接续：简体句子＋とすれば；名词、Ⅱ类形容词的非过去肯定形式使用「だ＋とすれば」。
- 译文：如果……；倘若……；假设……。

::: tip :bookmark: 说明

<grammer-content sentence='常与「仮に」「もし」呼应。后项常用「だろう」「はずだ」「たい」等形式。前项也可以使用过去形式，以假设过去的事实。' />

:::

::: info :books: 例句

1. <grammer-content sentence='このようなゆとりがあなたにある**とすれば**、それは[非常に/ひじょうに][幸せ/しあわせ]であるといえるでしょう。' trans='如果你有这样的从容和余裕，可以说是非常幸福的吧。' />
2. <grammer-content sentence='[人生/じんせい]がやり[直せ/なおせ]る**とすれば**、[学生時代/がくせいじだい]に[戻り/もどり]たい。' trans='如果人生可以重来，我想回到学生时代。' />
3. <grammer-content sentence='このクラスから[代表/だいひょう]を[選ぶ/えらぶ]**とすれば**、[彼/かれ][以外/いがい]にはいないだろう。' trans='如果要从这个班选一名代表，恐怕非他莫属吧。' />
4. <grammer-content sentence='[飛行機/ひこうき]で[行った/いった]**とすれば**、[今頃/いまごろ]は[着い/つい]ているはずだ。' trans='如果他是坐飞机去的，现在应该已经到了。' />
5. <grammer-content sentence='もし、[未来/みらい]にいける**とすれば**、[私/わたし]は100[年後/ねんご]の[世界/せかい]が[見た/みた]い。' trans='如果能去未来，我想看看一百年后的世界。' />
:::
