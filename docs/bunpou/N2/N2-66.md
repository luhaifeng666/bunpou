# Nに応じて<根据> <Badge type="danger" text="N2" />

* 意义：表示按照需要、条件或状况采取相应的措施，或作出相应的调整。
* 接续：名词+に応じて
* 译文：随着……；根据……；应……

::: info :books: 例句

1. <grammer-content sentence='[必要/ひつよう]**に[応じ/おうじ]て**この[二つ/ふたつ]を[使い分け/つかいわけ]るところが[日本語/にほんご]のユニークな[点/てん]だと[思い/おもい]ます。' trans='我觉得，能根据需要区分使用这两种说法，是日语的独特之处。' />
2. <grammer-content sentence='[参加人数/さんかにんずう]**に[応じ/おうじ]て**[場所/ばしょ]を[変更/へんこう]する[可能性/かのうせい]がある。' trans='可能会根据参加人数更改场地。' />
3. <grammer-content sentence='お[客/きゃく]様の**[要求/ようきゅう]に応じて**[様々/さまざま]な[サービス/さーびす]を[提供/ていきょう]します。' trans='根据客户的要求提供各种服务。' />
4. <grammer-content sentence='あの[店/みせ]は[季節/きせつ]**に[応じ/おうじ]て**メニューを[変え/かえ]ている。これも[人気/にんき]の[理由/りゆう]の[一つ/ひとつ]だ。' trans='那家店根据季节变换菜单。这也是它受欢迎的原因之一。' />
:::

::: tip :bookmark: 补充说明

<grammer-content sentence='「に応じて」强调随条件作相应的调整，例如店家按季节调整菜单。「によって」也可以只陈述因条件不同而产生的差别，例如「季節によってメニューが変わる」。' />

:::
