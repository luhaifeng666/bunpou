# ～ばかりに＜消极结果的原因＞ <Badge type="danger" text="N2" />

- 意义：强调某个原因引起了不如意的结果，常带有后悔、遗憾或不满的心情。
- 接续：动词、形容词的连体形＋ばかりに；名词＋である＋ばかりに。
- 译文：就因为……；只因为……（结果却……）。

::: tip :bookmark: 说明

1. Ⅱ类形容词的非过去肯定形式用「～な／～である」，如「下手なばかりに」；动词也可以使用过去或否定形式，如「断らなかったばかりに」。
2. 后项多为说话人不希望出现的结果。「ばかりに」强调说话人把这一结果归因于前项的事情。
3. <grammer-content sentence='「Vた＋ばかりに」' inline />在这里表示原因；[「Vたばかりだ」](../N3/2-01-36.md)则表示动作刚刚结束，注意区分。

:::

1. <grammer-content sentence='おばあさんのアドバイスを**[聞/き]き[入/い]れなかったばかりに**チャンスを[見逃/みのが]したよ。' trans='就因为没有听从奶奶的建议，结果错过了机会。' />
2. <grammer-content sentence='[私/わたし]が**[遅刻/ちこく]したばかりに**みんなに[迷惑/めいわく]をかけてしまった。' trans='就因为我迟到了，给大家添了麻烦。' />
3. <grammer-content sentence='はっきり**[断/ことわ]らなかったばかりに**[委員長/いいんちょう]にされてしまった。' trans='就因为没有明确拒绝，结果被推举成了委员长。' />
4. <grammer-content sentence='コミュニケーションが**[下手/へた]なばかりに**、[失敗/しっぱい]ばかりしている。' trans='就因为不善于沟通，总是出差错。' />
