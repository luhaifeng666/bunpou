# ～ぶり＜样态＞ <Badge type="danger" text="N2" />

- 意义：表示某种动作、生活或变化所呈现的样子、状态。
- 接续：名词／动词的第一连用形＋ぶり。
- 译文：……的样子；……的状况。

::: tip :bookmark: 说明

<grammer-content sentence='常见搭配有「成長ぶり」「生活ぶり」「慌てぶり」「話しぶり」「暮らしぶり」。这里的「ぶり」表示样态，不是「3年ぶり」中表示时隔多久的用法。' />

:::

::: info :books: 例句

1. <grammer-content sentence='その[急成長/きゅうせいちょう]**ぶり**には[国内外/こくないがい]から[驚き/おどろき]の[声/こえ]が[上が/あが]っている。' trans='对于这种迅速发展的势头，国内外都发出了惊叹。' />
2. <grammer-content sentence='[彼/かれ]の[生活/せいかつ]**ぶり**を[見て/みて]いると、[将来/しょうらい]が[心配/しんぱい]になる。' trans='看着他的生活状况，不禁为他的将来担心。' />
3. <grammer-content sentence='さっきの[彼女/かのじょ]の[慌て/あわて]**ぶり**からして、よっぽど[大き/おおき]なトラブルがあると[見え/みえ]る。' trans='从她刚才慌张的样子来看，似乎出了相当大的麻烦。' />
4. <grammer-content sentence='お[医者/いしゃ]さんは[患者/かんじゃ]さんの[表情/ひょうじょう]や[話し/はなし]**ぶり**に[気を/きを][配り/くばり]ながら[診察/しんさつ]を[行った/おこなった]。' trans='医生一边留意患者的表情和说话的样子，一边进行了诊察。' />
5. <grammer-content sentence='[街/まち]の[人々/ひとびと]の[暮らし/くらし]**ぶり**を[詳しく/くわしく][紹介/しょうかい]した[本/ほん]です。' trans='这是一本详细介绍城里人们生活状况的书。' />
:::
