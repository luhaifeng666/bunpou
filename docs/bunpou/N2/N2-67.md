# Nに応えて<回应> <Badge type="danger" text="N2" />

* 意义：表示根据对方的行为进行回应。多是对于要求、邀请、意见等的回应。
* 接续：名词+に応えて
* 译文：回应……；响应……

::: info :books: 例句

1. <grammer-content sentence='こちらの[要望/ようぼう]**に[応え/こたえ]て**いただき、ありがとうございます。' trans='感谢您回应了我们的请求。' />
2. <grammer-content sentence='お[客様/きゃくさま]の[要求/ようきゅう]**に[応え/こたえ]て**、[来月/らいげつ]から[営業時間/えいぎょうじかん]を[一時間/いちじかん][延長/えんちょう]させていただきます。' trans='应顾客要求，我们将从下个月起延长营业时间一小时。' />
3. <grammer-content sentence='[結果/けっか]は[最下位/さいかい]となり、[皆さん/みなさん]のご[声援/せいえん]**に[応え/こたえ]られず**、[申し訳/もうしわけ]ございませんでした。' trans='最后只拿到了末名，没能回报大家的支持，非常抱歉。' />
:::

::: tip :bookmark: 补充说明

<grammer-content sentence='回应请求、期待或声援时用「応える」。回答问题时通常用「答える」，如「質問に答える」。' />

:::
