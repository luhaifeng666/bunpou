# ～こともあって＜原因之一＞ <Badge type="danger" text="N2" />

- 意义：提出引起后项事情的一个原因，暗示还存在其他原因。
- 接续：动词、形容词的连体形＋こともあって／こともあり；名词＋という＋こともあって／こともあり。
- 译文：也因为……；也有……的原因。

::: tip :bookmark: 说明

<grammer-content sentence='「こともあり」多用于书面语。Ⅱ类形容词的非过去肯定形式用「～なこともあって」，如「地味なこともあって」。' />

:::

::: info :books: 例句

1. <grammer-content sentence='[中国/ちゅうごく]アニメ[産業/さんぎょう]は、ここ[数年/すうねん]、[国/くに]を[挙げ/あげ]てバックアップしている**こともあり**、[飛躍的/ひやくてき]に[成長/せいちょう]を[遂げ/とげ]ている。' trans='中国动画产业近几年也得益于举国支持，取得了飞跃式的发展。' />
2. <grammer-content sentence='お[腹/なか]が[空い/すい]ていた**こともあって**とてもおいしく[食べ/たべ]ました。' trans='也因为肚子饿了，吃起来觉得特别美味。' />
3. <grammer-content sentence='ダイエット[中/ちゅう]という**こともあり**、お[酒/さけ]を[飲ま/のま]ないようにしている。' trans='也因为正在减肥，我尽量不喝酒。' />
4. <grammer-content sentence='みんな[年/とし]が[近/ちか]い**こともあって**、[同世代/どうせだい]ならではの[話/はなし]で[盛り上が/もりあが]っています。' trans='也因为大家年龄相近，聊起同龄人特有的话题，气氛很热烈。' />
5. <grammer-content sentence='[息子/むすこ]は[性格的/せいかくてき]に[地味/じみ]な**こともあって**、[演奏家/えんそうか]には[向い/むい]ていないと[思い/おもい]ます。' trans='也因为儿子的性格比较低调，我认为他不太适合做演奏家。' />
