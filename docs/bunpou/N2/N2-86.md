# Vるのだった＜后悔＞ <Badge type="danger" text="N2" />

- 意义：回想过去，表示当时本应采取某个行动，却没有做到而感到后悔。
- 接续：自主动词的辞典形＋のだった；口语中常用「Vるんだった」。
- 译文：要是当时……就好了；当初应该……的。

::: tip :bookmark: 说明

<grammer-content sentence='「Vるのではなかった／Vるんじゃなかった」表示后悔做了某事，意思是“当初不该……”。这里的过去形式表达回顾、后悔，并不是说该动作已经实现。' />

:::

::: info :books: 例句

1. <grammer-content sentence='ああ、[予習/よしゅう]をしておく**のだった**。' trans='唉，当初应该先预习的。' />
2. <grammer-content sentence='あの[時/とき]、[彼女/かのじょ]に[本当/ほんとう]の[気持ち/きもち]を[伝え/つたえ]る**んだった**。' trans='那时候应该把真实的心意告诉她的。' />
3. <grammer-content sentence='こんなに[大変/たいへん]な[仕事/しごと]なら、[断る/ことわる]**んだった**。' trans='早知道工作这么辛苦，当初就该拒绝的。' />
4. <grammer-content sentence='あと[10分/じゅっぷん]あれば[新幹線/しんかんせん]に[間に合っ/まにあっ]たのに。もう[少し/すこし][早く/はやく][家/いえ]を[出る/でる]**んだった**。' trans='要是再有十分钟就赶得上新干线了。当初应该再早点出门的。' />
5. <grammer-content sentence='しまった！あのメールは[一度/いちど]チェックしてから[送る/おくる]**んだった**。' trans='糟了！那封邮件应该检查一遍再发的。' />
6. <grammer-content sentence='[授業/じゅぎょう]についていけない。サボる**んじゃなかった**！' trans='跟不上课了。早知道就不该逃课！' />
