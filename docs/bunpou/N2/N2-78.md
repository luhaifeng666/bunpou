# ～に限る＜最佳选择＞ <Badge type="danger" text="N2" />

- 意义：表示说话人认为在当前情况下最好的选择或做法。
- 接续：名词／动词的辞典形／动词的ない形＋に限る。
- 译文：最好是……；……再好不过。

::: tip :bookmark: 说明

<grammer-content sentence='这是对最佳选择的评价，与「Nに限らず」表示不限于某个范围的用法不同。' />

:::

::: info :books: 例句

1. <grammer-content sentence='[寒/さむ]い[日/ひ]は、[熱々/あつあつ]の[鍋/なべ]**に[限る/かぎる]**。' trans='寒冷的日子里，吃热腾腾的火锅再好不过了。' />
2. <grammer-content sentence='[風邪/かぜ]を[引い/ひい]たら、[薬/くすり]を[飲ん/のん]で、ゆっくり[休む/やすむ]**に[限り/かぎり]ます**。' trans='感冒了，最好是吃药后好好休息。' />
3. <grammer-content sentence='[仕事/しごと]で[疲れ/つかれ]たときは、お[風呂上が/ふろあが]りの[冷え/ひえ]たビール**に[限る/かぎる]**と[父/ちち]がよく[言って/いって]いた。' trans='父亲常说，工作累了的时候，洗完澡喝杯冰啤酒最好。' />
:::
