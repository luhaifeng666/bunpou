# ～にもかかわらず＜转折＞ <Badge type="danger" text="N2" />

- 意义：表示实际出现的结果与根据前项情况通常可以作出的预期相反。
- 接续：动词、Ⅰ类形容词的简体形式＋にもかかわらず；名词、Ⅱ类形容词词干＋にもかかわらず。
- 译文：尽管……却……；虽然……但是……。

::: tip :bookmark: 说明

<grammer-content sentence='也可以在句号后单独使用「にもかかわらず」，承接前文。注意与「～にかかわらず」表示不受某条件影响的用法区分。' />

相关用法：[～にかかわらず＜无区别＞](N2-35.md)。

:::

::: info :books: 例句

1. <grammer-content sentence='[雨天/うてん]**にもかかわらず**[来て/きて]くださって、ありがとうございます。' trans='尽管下雨，您还是来了，非常感谢。' />
2. <grammer-content sentence='[努力/どりょく]した**にもかかわらず**、[失敗/しっぱい]してしまった。' trans='尽管付出了努力，结果还是失败了。' />
3. <grammer-content sentence='[何度/なんど]も[警告し/けいこくし]た。**にもかかわらず**、[彼女/かのじょ]は[聞か/きか]なかった。' trans='已经警告过她很多次了。尽管如此，她还是没有听。' />
:::
