# Vてでも＜为达目的采取的手段＞ <Badge type="danger" text="N2" />

- 意义：表示即使采取代价较大或通常不愿采取的手段，也要实现后项的目的。
- 接续：动词的て形＋でも。
- 译文：就算……也要……；哪怕……也要……。

::: tip :bookmark: 说明

<grammer-content sentence='后项常表达强烈的愿望、意志或必要性。这里的「でも」不是举例，而是突出为达到目的所能接受的手段或代价。' />

相关用法：[Nまでして／Vてまで＜极端程度＞](N2-33.md)。

:::

1. <grammer-content sentence='[今日/きょう]は[徹夜/てつや]し**てでも**この[仕事/しごと]を[終わ/おわ]らせなければならない。' trans='今天哪怕熬夜也必须把这项工作做完。' />
2. <grammer-content sentence='[姉/あね]は[昔/むかし]から「[欲しい/ほしい]ものは[借金/しゃっきん]し**てでも**[買う/かう]」タイプの[人/ひと]だ。' trans='姐姐一直是那种“想要的东西哪怕借钱也要买”的人。' />

4. <grammer-content sentence='[怪我/けが]は[少し/すこし][痛む/いたむ]けど、[決勝戦/けっしょうせん]なので[無理/むり]し**てでも**[出場/しゅつじょう]したい。' trans='伤口虽然还有些疼，但这是决赛，哪怕勉强自己也想上场。' />
