# Nにかけては＜积极评价＞ <Badge type="danger" text="N2" />

- 意义：就某个方面对人或事物作积极评价，强调其在这一方面出色。
- 接续：名词＋にかけては。
- 译文：在……方面（很出色）；论……（无人能比）。

::: tip :bookmark: 说明

<grammer-content sentence='前面的名词表示评价的方面，后项常用「一番だ」「定評がある」「だれにも負けない」等积极评价的表达。' />

:::

::: info :books: 例句

1. <grammer-content sentence='デザイン**にかけては**、このカメラが[一番/いちばん]だと[思う/おもう]。' trans='论设计，我认为这台相机是最好的。' />
2. <grammer-content sentence='[彼女/かのじょ]は[職場/しょくば]ではあまり[目立た/めだた]ないが、[仕事/しごと]の[速さ/はやさ]**にかけては**[定評/ていひょう]がある。' trans='她在工作单位虽然不太起眼，但工作速度之快有口皆碑。' />
3. <grammer-content sentence='わたしは[安い/やすい][材料/ざいりょう]でおいしい[料理/りょうり]を[作る/つくる]こと**にかけては**だれにも[負け/まけ]ませんよ。' trans='说到用便宜的食材做出美味的料理，我可不输给任何人。' />
:::
