# ～とかで＜不确定的原因＞ <Badge type="danger" text="N2" />

- 意义：引用听说的或记忆不确切的信息，把它作为后项事情的原因。
- 接续：简体句子＋とかで；名词、Ⅱ类形容词的非过去肯定形式通常直接接「とかで」。
- 译文：说是因为……；好像是因为……。

::: tip :bookmark: 说明

<grammer-content sentence='「とか」表示不确切的引用，「で」表示原因，常用于口语。说话人没有明确确认该信息，并不等于断定信息不可信。' />

相关用法：[～とか＜不确切的间接引语＞](../N3/N3-33.md)。

:::

::: info :books: 例句

1. <grammer-content sentence='[彼は/かれは][風邪/かぜ]を[引い/ひい]た**とかで**[今日/きょう]は[欠席/けっせき]するらしい。' trans='说是感冒了，他今天好像不来了。' />
2. <grammer-content sentence='この[先/さき]は[事故/じこ]**とかで**[渋滞/じゅうたい]している。' trans='前面好像是因为事故堵车了。' />
3. <grammer-content sentence='[私/わたし]に[何か/なにか][重要な/じゅうような][話/はなし]がある**とかで**、[突然/とつぜん][呼び出さ/よびださ]れた。' trans='说是有重要的事要跟我说，突然把我叫了出去。' />
:::
