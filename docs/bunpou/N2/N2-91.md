# ～うえに＜累加＞ <Badge type="danger" text="N2" />

- 意义：在前项情况的基础上，再加上具有相同评价方向的后项情况。
- 接续：动词、形容词的连体形＋うえに；名词＋である＋うえに。
- 译文：不仅……而且……；再加上……。

::: tip :bookmark: 说明

<grammer-content sentence='好的情况与好的情况相加，不好的情况与不好的情况相加。后项常用「も」呼应；有时可以省略「に」，只用「うえ」。' />

<grammer-content sentence='名词接续应结合具体语境理解；表达某人的身份或属性时，用「Nであるうえに」可明确表示累加。' />

:::

::: info :books: 例句

1. <grammer-content sentence='[山田/やまだ]くんは[勉強/べんきょう]ができる**[上に/うえに]**、スポーツも[得意/とくい]なので、クラスの[人気者/にんきもの]だ。' trans='山田不仅学习好，而且擅长运动，所以在班里很受欢迎。' />
2. <grammer-content sentence='[台風/たいふう]が[近づ/ちかづ]いてきて、[風/かぜ]が[強い/つよい]**[上/うえ]**、[雨/あめ]も[激しく/はげしく][降っ/ふっ]ている。' trans='台风逐渐逼近，不仅风大，雨也下得很猛烈。' />
3. <grammer-content sentence='この[商品/しょうひん]はデザインがユニークな**[上に/うえに]**、[色/いろ]もカラフルだ。' trans='这件商品不仅设计独特，颜色也很丰富。' />
