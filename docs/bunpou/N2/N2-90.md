# ～うえで＜范围／先后顺序＞ <Badge type="danger" text="N2" />

## Vる／Nの＋うえで＜判断成立的范围＞

- 意义：表示作出后项判断、说明其重要性或作用时所涉及的方面或范围。
- 接续：动词的辞典形＋うえで；名词＋の＋うえで。
- 译文：在……方面；在……上；对于……来说。

::: tip :bookmark: 说明

<grammer-content sentence='这里的「Vる＋うえで」不表示动作已经完成。不要与下面「Vた＋うえで」表示先完成某事的用法混淆。' />

:::

::: info :books: 例句

1. <grammer-content sentence='[関連/かんれん][業界/ぎょうかい]を[成熟/せいじゅく]させる**[上で/うえで]**、[伝統/でんとう][文化/ぶんか]の[継承/けいしょう]・[保護/ほご]、[最新技術/さいしんぎじゅつ]の[導入/どうにゅう]、[人材/じんざい]の[育成/いくせい]などが、[最も/もっとも][重要な/じゅうような][点/てん]となる。' trans='在促进相关产业成熟的过程中，传统文化的传承与保护、新技术的引进及人才培养等是最重要的环节。' />
2. <grammer-content sentence='パスポートは[海外旅行/かいがいりょこう]する**[上で/うえで]**[一番重要/いちばんじゅうよう]な[書類/しょるい]なので、[大事/だいじ]に[保管/ほかん]しなければならない。' trans='护照是出国旅行时最重要的证件，必须妥善保管。' />
3. <grammer-content sentence='アニメやドラマは[外国語/がいこくご][学習/がくしゅう]の**[上で/うえで]**[重要な/じゅうような][役割/やくわり]を[担っ/になっ]ている。' trans='动画和电视剧在外语学习方面发挥着重要作用。' />
4. <grammer-content sentence='その[人/ひと]とは[仕事/しごと]の**[上で/うえで]の**つきあいだけだ。' trans='我和那个人只有工作上的往来。' />
5. <grammer-content sentence='[経済/けいざい]・[社会/しゃかい][発展/はってん]のグリーン[化/か]・[低/てい][炭素/たんそ][化/か]の[推進/すいしん]は[質/しつ]の[高い/たかい][発展/はってん]を[実現/じつげん]する**[上で/うえで]**カギとなる[部分/ぶぶん]である。' trans='推动经济社会发展绿色化、低碳化，是实现高质量发展的关键环节。' />
:::

## Vた／Nの＋うえで＜在此基础上＞

- 意义：表示先完成前项动作，再在其基础上进行后项动作、作出判断或安排。
- 接续：动词的た形＋うえで；动作性名词＋の＋うえで。
- 译文：在……之后；在……的基础上。

::: tip :bookmark: 说明

<grammer-content sentence='强调前项是后项的前提或准备，而不只是两件事情在时间上有先后关系。' />

相关用法：[Vてから＜先后顺序＞](../N3/2-01-04.md)。

:::
