# V（ら）れる＜尊他＞ <Badge type="warning" text="N4" />

* <grammer-content sentence='意义：用尊他形式描述动作，表示对动作主体的敬意。' />
* 接续：动词词干＋（ら）れる，与被动态形式相同
* 译文：（您）……

::: tip :bookmark: 活用形

<grammer-content sentence='**Ⅰ类动词**：[書/か]く → [書/か]かれる、[読/よ]む → [読/よ]まれる。' />

<grammer-content sentence='**Ⅱ类动词**：[借/か]りる → [借/か]りられる、[教/おし]える → [教/おし]えられる。' />

<grammer-content sentence='**Ⅲ类动词**：[来/く]る → [来/こ]られる、する → される。' />

:::

::: warning :warning: 注意

<grammer-content sentence='「V（ら）れる」也可以表示被动、自发或可能，具体用法要结合句子结构和语境判断。' />

其他尊他形式和动词对照可参见[敬语](../../term/keigo.md)。

:::

::: info :books: 例句

1. <grammer-content sentence='[昨日/きのう]、[胡/こ][先生/せんせい]が**来られて**（[来/き]て）、[教/おし]えてくださいました。' trans='昨天胡老师来了，告诉了我。' />
2. <grammer-content sentence='あの[方/かた]は、[東西/とうざい][大学/だいがく]で[中国/ちゅうごく][史学/しがく]を**専攻されました**。' trans='那位先生在东西大学专攻中国史学。' />
3. <grammer-content sentence='この[本/ほん]は、[遠藤/えんどう][先生/せんせい]が**書かれた**[本/ほん]です。' trans='这本书是远藤老师写的书。' />

:::
