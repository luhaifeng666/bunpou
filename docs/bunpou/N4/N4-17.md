# ～だけ＜限定／程度＞ <Badge type="warning" text="N4" />

「だけ」既可以限定事物或动作，也可以表示所能达到、所希望达到或完成某事所需的程度。

## だけ＜限定＞

- 意义：限定所述的事物、动作或状态。
- 接续：名词／动词、形容词的连体形＋だけ。
- 译文：只……；仅仅……。

::: tip :bookmark: 说明

<grammer-content sentence='表示限定时，可以用「～だけで」连接后面的说明，也可以用「～だけだ／だけです」结句。' />

如果要表达“光凭……还不够”“仅仅……无法做到”，可以使用[「～だけでは」](../N2/N2-11.md)。

:::

::: info :books: 例句

1. <grammer-content sentence='ちょっとのぞく**だけ**……。' trans='只是稍微看看……' />
2. <grammer-content sentence='[彼/かれ]は[文句/もんく]を[言/い]う**だけで**、[何/なに]も[手伝/てつだ]ってくれない。' trans='他只是发牢骚，什么都不帮忙。' />
3. <grammer-content sentence='あの[店/みせ]の[料理/りょうり]は[高/たか]い**だけで**[全然/ぜんぜん][美味/おい]しくない。' trans='那家店的菜只是贵，一点都不好吃。' />
4. <grammer-content sentence='[彼/かれ]はコミュニケーションが[嫌/きら]いなんじゃなく、[苦手/にがて]な**だけ**だと[思/おも]う。' trans='我觉得他不是讨厌交流，只是不擅长而已。' />

:::

## だけ＜可达到的程度＞

- 意义：表示按照能力、愿望等所允许的限度，尽可能充分地进行某个动作。
- 接续：动词的可能形／Vたい／部分形容词的连体形＋だけ。
- 译文：尽可能……；能……多少就……多少；想……多少就……多少。

::: tip :bookmark: 说明

1. 「动词的可能形＋だけ＋同一动词」表示在能力允许的范围内尽量进行该动作，如「食べられるだけ食べる」。
2. 「Vたい＋だけ＋同一动词」表示按照自己的愿望进行该动作，如「寝たいだけ寝る」。
3. <grammer-content sentence='常见表达还有「できるだけ」「好きなだけ」「欲しいだけ」。' />

:::

::: info :books: 例句

1. <grammer-content sentence='[明日/あした]は**できるだけ**[早/はや]く[来/き]てください。' trans='明天请尽可能早点来。' />
2. <grammer-content sentence='**[食/た]べられるだけ**[食/た]べた。' trans='能吃多少就吃了多少。' />
3. <grammer-content sentence='**[頑張/がんば]れるだけ**[頑張/がんば]ってみる。' trans='我会尽自己所能努力试试看。' />
4. <grammer-content sentence='[日曜日/にちようび]は**[寝/ね]たいだけ**[寝/ね]ることができる。' trans='周日想睡多久就能睡多久。' />
5. <grammer-content sentence='[遠慮/えんりょ]しないで、**[食/た]べたいだけ**[食/た]べなさい。' trans='别客气，想吃多少就吃多少吧。' />
6. <grammer-content sentence='[好/す]きなものを**[好/す]きなだけ**[食/た]べなさい。' trans='喜欢吃的东西，想吃多少就吃多少吧。' />
7. <grammer-content sentence='どうしたらお[金/かね]が**[欲/ほ]しいだけ**[手/て]に[入/はい]るのか。' trans='怎样才能想要多少钱就得到多少钱呢？' />
8. <grammer-content sentence='せっかく[中国/ちゅうごく]に[来/き]たんだから、[中国/ちゅうごく]の[世界遺産/せかいいさん]を**[見/み]られるだけ**[見/み]たい。' trans='难得来中国，我想尽可能多地看看中国的世界遗产。' />

:::

## だけのN＜所需的程度＞

- 意义：表示后面的名词所指的数量、能力或条件，足以实现前面所说的动作或状态。
- 接续：动词的连体形＋だけの＋名词。
- 译文：足够……的……；足以……的……。

::: info :books: 例句

1. <grammer-content sentence='どんな[事態/じたい]になったときでも、それに**[動/どう]じないだけの**[心/こころ]を[持/も]たなければなりません。' trans='必须有足够坚定的内心，无论遇到什么情况都能保持镇定。' />
2. <grammer-content sentence='**[生/い]きていけるだけの**[収入/しゅうにゅう]があれば、あとは[自分/じぶん]の[好/す]きなことをしたい。' trans='只要有足以维持生活的收入，除此以外，我想做自己喜欢的事。' />
3. <grammer-content sentence='[頑張/がんば]って[貯金/ちょきん]していても、**[家/いえ]を[買/か]うだけの**お[金/かね]は[簡単/かんたん]に[貯/た]まらない。' trans='即使努力存钱，也不容易攒够买房的钱。' />

:::
