# ～わけがない＜强烈否定＞ <Badge type="warning" text="N3" />

- 意义：说话人根据已知情况，强烈否定某件事发生或成立的可能性。
- 接续：动词、形容词的连体形＋わけがない；名词＋の／である＋わけがない。
- 译文：不可能……；怎么可能……。

::: tip :bookmark: 说明

<grammer-content sentence='口语中也可以说「わけない」。当「わけがない」前面是否定形式时，整个句子表达肯定判断，如「知らないわけがない」表示“不可能不知道”。' />

<grammer-content sentence='不要与「～わけではない／わけじゃない」表示并非如此的部分否定混淆。' />

相关用法：[～わけじゃない＜部分否定＞](N3-29.md)。

:::

::: info :books: 例句

1. <grammer-content sentence='[十年/じゅうねん]もピアノを[習っ/ならっ]ている[彼女/かのじょ]にこの[曲が/きょくが]**ひけないわけがない**。' trans='她学了整整十年钢琴，不可能不会弹这首曲子。' />
2. <grammer-content sentence='そのことなら、すでに[知らせ/しらせ]たんだから、**[知ら/しら]ないわけがない**。' trans='那件事已经通知过他了，他不可能不知道。' />
3. <grammer-content sentence='[鈴木/すずき][先輩/せんぱい]は[病気/びょうき]で[入院中/にゅういんちゅう]なんだよ。[今/いま]ここにいる**わけがない**んじゃない。' trans='铃木前辈因病正在住院，不可能现在出现在这里吧。' />
:::
