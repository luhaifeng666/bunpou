# Vるところだ / Vているところだ / Vたところだ / Vていたところだ〈动作阶段与说话时点的关系〉 <Badge type="warning" text="N3" />

- <grammer-content sentence='意义：以说话时点为参照，表示动作即将开始、正在进行、刚刚结束，或此前持续的状态。' />
- 接续：动词的辞典形／ている／た形／ていた＋ところだ
- 译文：
  - <grammer-content sentence='Vるところだ：现在正要……' />
  - <grammer-content sentence='Vているところだ：现在正在……' />
  - <grammer-content sentence='Vたところだ：刚刚……完' />
  - <grammer-content sentence='Vていたところだ：刚才一直在……' />

### a. Vるところだ

<grammer-content sentence='表示动作在说话时即将开始，常与「[今/いま]」「ちょうど」「これから」等时间副词搭配。' />

::: info :books: 例句

1. <grammer-content sentence='それでお[土産/みやげ]を[買/か]いに[行/い]く**ところ**なんです。' trans='因此要去买土特产。' />
2. <grammer-content sentence='[今/いま]、[出/で]かける**ところ**です。' trans='现在正要出门。' />
3. <grammer-content sentence='これから[寮/りょう]を[出/で]る**ところ**ですから、15[分/ぷん]ぐらい[待/ま]ってください。' trans='马上就要离开宿舍了，请等15分钟左右。' />

:::

### b. Vているところだ

表示该动作行为在说话时正在进行之中，经常与「今、ちょうど」等时间副词搭配使用。

::: info :books: 例句

1. <grammer-content sentence='[今/いま]、彼女とチャットをしている**ところ**です。' trans='现在正在和女朋友聊天。' />
2. <grammer-content sentence='ちょうどお[風呂/ふろ]に[入/はい]っている**ところ**です。' trans='现在正在洗澡。' />
3. <grammer-content sentence='ご[飯/はん]を**[食べて/たべて]いるところ**。' trans='我正在吃饭。' />

:::

### c. Vたところだ

表示该动作行为在说话时刚刚结束，经常与「今、たったいま」等时间副词搭配使用。

::: info :books: 例句

1. <grammer-content sentence='[今/いま]、[授業/じゅぎょう]が[終/お]わった**ところ**です。' trans='现在刚刚下课。' />
2. <grammer-content sentence='[李/り]さんはたった[今/いま]、[大学/だいがく]から[寮/りょう]に[帰/かえ]って[来/き]た**ところ**です。' trans='小李现在刚从大学回到宿舍。' />
3. <grammer-content sentence='[今/いま]、[遠足/えんそく]の[日/ひ]を[決/き]めてみんなに**[連絡/れんらく]したところ**だ。' trans='我刚刚决定了郊游日期，并通知了大家。' />

:::

### d. Vていたところだ

表示从过去某一时点到说话之前该状态一直在持续，多用来说明之前持续的思考行为或心理状态。

::: info :books: 例句

1. <grammer-content sentence='[僕/ぼく]もそろそろ[帰/かえ]ろうと[思/おも]っていた**ところ**だ。' trans='我刚才也一直在想差不多该回去了。' />
2. <grammer-content sentence='なかなか[連絡/れんらく]がないから[心配/しんぱい]していた**ところ**だよ。' trans='因为一直没有联系，我刚才一直在担心。' />
3. <grammer-content sentence='[休も/やすも]うかどうしようかと**[考え/かんがえ]ていたところ**だ。' trans='我刚才一直在想要不要休息。' />

:::
