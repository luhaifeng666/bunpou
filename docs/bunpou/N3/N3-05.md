# Vずに＜动作の否定＞ <Badge type="warning" text="N3" />

* <grammer-content sentence='意义：表示没有做前项动作，在这种状态下做了后项动作。' />
* 接续：动词的ない形去掉「ない」＋ずに（する→せずに）
* 译文：不（没）……（的情况下）

::: tip :bookmark: 説明

<grammer-content sentence='「Vずに」与「Vないで」都可以表示未做前项动作，前者较多用于书面语。' />

<grammer-content sentence='前后分句只表示并列或对照时，使用「Vないで」或「Vず」。「Vずに」通常把前项作为后项动作的伴随状态。' />

:::

::: info :books: 例句

1. <grammer-content sentence='よく[考/かんが]え**ずに**、[親/おや]に[行/い]けと[言/い]われた[大学/だいがく]を[目指/めざ]して、[頑張/がんば]っていました。' trans='没有认真考虑，就把父母让考的大学当做目标来努力。' />
2. <grammer-content sentence='[彼/かれ]は[今/いま]は1[日/にち]も[休/やす]ま**ずに**、まじめに[働/はたら]いています。' trans='他现在一天也不休息，认真地工作着。' />
3. <grammer-content sentence='[復習/ふくしゅう]もせ**ずに**[期末試験/きまつしけん]を[受/う]けたら、[不合格/ふごうかく]だった。' trans='没有复习就参加了期末考试，结果不及格。' />
4. <grammer-content sentence='この[仕事/しごと]は、[誰/だれ]にも[手伝/てつだ]ってもらわ**ずに**、[自分/じぶん]でしました。' trans='这份工作没有让任何人帮忙，自己做了。' />
5. <grammer-content sentence='[王/おう]さんは[返事/へんじ]**しないで**、[李/り]さんは[返事/へんじ]した。' trans='小王没有回复，小李回了。' />

:::
