# 被动态与被动句(1)〈直接被动句〉 <Badge type="warning" text="N3" />

- <grammer-content sentence='意义：表示主语所指的人或事物承受某个动作。' />
- 接续：
  - <grammer-content sentence='Ⅰ类动词：将词尾的う段假名改成相应的あ段假名，再加「れる」。如「[書/か]く → [書/か]かれる」。以「う」结尾时改为「わ」，如「[言/い]う → [言/い]われる」。' />
  - <grammer-content sentence='Ⅱ类动词：去掉词尾「る」，再加「られる」。如「[見/み]る → [見/み]られる」。' />
  - <grammer-content sentence='Ⅲ类动词：「[来/く]る → [来/こ]られる」「する → される」。' />
- 译文：被......；受到......；遭到......

::: info :books: 说明

<grammer-content sentence='按意义和结构，可分为直接被动句、物主被动句和间接被动句。直接被动句的主语对应主动句中由「を」或「に」标记的对象。' />

:::

### 直接被动句 No.1

**N1（人）が N2（人）に V（ら）れる**

<grammer-content sentence='这是典型的直接被动句，对应主动句「N2（人）が N1（人）を／に Vる」。' />

::: info :books: 例句

1. <grammer-content sentence='[子供/こども]が[母親/ははおや]に**[叱/しか]られる**。' trans='孩子被母亲训斥。' />
2. <grammer-content sentence='[息子/むすこ]がクラスメートに**[苛/いじ]められる**。' trans='儿子被同学欺负。' />
3. <grammer-content sentence='[孫/まご]がおばあさんに**[育/そだ]てられる**。' trans='孙子被奶奶抚养。' />
4. <grammer-content sentence='（[私/わたし]は）[高橋/たかはし]さんに**[招待/しょうたい]された**。' trans='我被高桥先生招待了。' />
5. <grammer-content sentence='[友達/ともだち]に**[誘わ/さそわ]れて**、[久し/ひさし]ぶりにコンサートに[行った/いった]。' trans='受朋友邀请，我久违地去听了一场音乐会。' />

:::

### 直接被动句 No.2

**N1（人）が N2（人）に/から N3を V（ら）れる**

当谓语动词为表示语言行为或感情、态度的他动词时，往往句中会增加一个表行为、态度对象的"を格"名词。

::: info :books: 例句

1. <grammer-content sentence='[私/わたし]は[上司/じょうし]に[仕事/しごと]を**[頼/たの]まれた**。' trans='我被上司拜托了工作。' />
2. <grammer-content sentence='[私/わたし]は[先生/せんせい]にいろいろなことを**[聞/き]かれた**。' trans='我被老师问了各种各样的事情。' />
3. <grammer-content sentence='[友達/ともだち]に[将来/しょうらい]の[仕事/しごと]について**[相談/そうだん]されました**が、いいアドバイスができませんでした。' trans='朋友就将来的工作向我征求意见，但我没能给出好的建议。' />
4. <grammer-content sentence='[周り/まわり]の[人/ひと]から**[反対/はんたい]されても**、[自分/じぶん]がどうしたいかということがいちばん[大事/だいじ]だと[思う/おもう]。' trans='即使受到周围人的反对，我认为最重要的还是自己想怎么做。' />

:::

### 直接被动句 No.3

**N1（物・こと）が N2（人）に V（ら）れる**

主语为表示物体或事件的名词，多用于客观地描述某一现象。

::: info :books: 例句

1. <grammer-content sentence='この[本/ほん]は[多/おお]くの[人/ひと]に**[読/よ]まれている**。' trans='这本书被很多人读。' />
2. <grammer-content sentence='[緑茶/りょくちゃ]は[中国/ちゅうごく]でよく**[飲/の]まれている**。' trans='绿茶在中国经常被喝。' />
3. <grammer-content sentence='2022[年/ねん]の[冬季/とうき]オリンピックは[北京/ペキン]で**[開/ひら]かれました**。' trans='2022年冬季奥运会在北京召开。' />
4. <grammer-content sentence='[中国/ちゅうごく]がどのように**[紹介/しょうかい]され**、[日本人/にほんじん]の[学生/がくせい]にどのように**[受/う]け[止/と]められている**か、ぜひ[知り/しり]たいんです。' trans='我很想知道中国是如何被介绍的，以及日本学生是如何理解和接受这些介绍的。' />
5. <grammer-content sentence='この[問題/もんだい]は[複雑/ふくざつ]だと**[考え/かんがえ]られている**。' trans='这个问题被认为很复杂。' />

:::

::: tip :bookmark: 补充说明

<grammer-content sentence='当动作主体泛指一般人或无须指出时，可以省略表示动作主体的「に格」名词。' />

:::

### 直接被动句 No.4

**N1（物・こと）が N2（人）によって V（ら）れる**

主语为表示物体或事件的名词，谓语是表示发明、创造或发现一类的动词（如「作る、発明する、設計する、書く」等），此时动作的主体一般不用"に格"表示，而要用「によって」。

::: info :books: 例句

1. <grammer-content sentence='この[製品/せいひん]はイギリス[人/じん]のデザイナーによって**[作/つく]られた**。' trans='这个产品是由英国设计师制作的。' />
2. <grammer-content sentence='この[建物/たてもの]は[有名/ゆうめい]な[建築家/けんちくか]によって**[設計/せっけい]されました**。' trans='这个建筑物是由著名的建筑师设计的。' />
3. <grammer-content sentence='[中国/ちゅうごく]は[秦/しん]の[始皇帝/しこうてい]によって**[統一/とういつ]されました**。' trans='中国由秦始皇统一。' />
4. <grammer-content sentence='[日本/にほん]のポップカルチャーがどのような[人々/ひとびと]によって**[作ら/つくら]れている**のか、[興味/きょうみ]を[持ち/もち]ました。' trans='我对日本的流行文化是由什么样的人创造出来的产生了兴趣。' />

:::
