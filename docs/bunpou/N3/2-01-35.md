# 使动被动态与使动被动句 <Badge type="warning" text="N3" />

- 意义：在他人的强迫或命令下，不得不去做不情愿的事情。
- 译文：被迫；不得不
- 接续：先变成使动态「～せる / させる」，然后在使动态的第一连用形后面接上表示被动的后缀「られる」

::: info :books: 说明

动词类别变化规则：
- I类动词：買う → 買わせる → 買わせられる / 買わされる
- II类动词：出る → 出させる → 出させられる
- III类动词：来る → 来させる → 来させられる；する → させる → させられる

:::

::: info :books: 例句

1. <grammer-content sentence='これ、（[私/わたし]は）父に**[持/も]たされて**来たんですよ。[ちょっと/ちょっと][重/おも]かったけど。' trans='这个，是我爸让我带过来的，虽然稍微有点重。' />
2. <grammer-content sentence='[子供/こども]はお[母/かあ]さんに[薬/くすり]を**[飲/の]まされました** / **[飲/の]ませられました**。' trans='孩子被妈妈要求吃药。' />
3. <grammer-content sentence='[昨日/きのう]、[私/わたし]は[病院/びょういん]で2[時間/じかん]ぐらい**[待た/また]されました**。' trans='昨天，我在医院被迫等了两个小时左右。' />
4. <grammer-content sentence='[私/わたし]は[先輩/せんぱい]からいろいろな[話/はなし]を**[聞か/きか]された**。' trans='我被迫听前辈讲了各种各样的事情。' />
5. <grammer-content sentence='[税関/ぜいかん]の[係員/かかりいん]にかばんの[中の/なかの][果物/くだもの]を**[出さ/ださ]せられた**。' trans='海关工作人员要求我把包里的水果拿出来。' />

:::

::: tip :bookmark: 补充说明
