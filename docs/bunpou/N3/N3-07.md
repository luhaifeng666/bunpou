# 非自发动词が「可能」の意味を表す <Badge type="warning" text="N3" />

* <grammer-content sentence='意义：一部分非自主动词本身就带有可能的意义，一般称为「[無標可能/むひょうかのう]」。' />
* 接续：直接使用相应的自动词，如「見える」「見つかる」。
* 译文：能够……；可以……

::: tip :bookmark: 説明

<grammer-content sentence='自主动词常用「Vることができる」或动词可能形表示能力或条件允许。部分非自主动词可直接表达类似的意义。' />

<grammer-content sentence='常见的有「[見/み]つかる」「[開/あ]く」「[上/あ]がる」「[入/はい]る」「[続/つづ]く」「[決/き]まる」「つく」，也有「[見/み]える」「[聞/き]こえる」「わかる」「[慣/な]れる」等。' />

:::

::: info :books: 例句

1. <grammer-content sentence='まだ[答/こた]えは**見つかっていません**が、[自分/じぶん]とは[何/なに]かを[考/かんが]えることから[哲学/てつがく]に[興味/きょうみ]を[持/も]つようになり、[哲学科/てつがくか]に[編入/へんにゅう]しました。' trans='虽然还没有找到答案，但从思考"自己是什么"开始对哲学产生了兴趣，转到了哲学专业。' />
2. <grammer-content sentence='いくら[押/お]してもドアが**開かない**。' trans='怎么推门也打不开。' />
3. <grammer-content sentence='[交換留学/こうかんりゅうがく]のことはなかなか**決まらない**。' trans='交换留学的事情怎么也定不下来。' />
4. <grammer-content sentence='**[治/なお]る**[病気/びょうき]だから[大丈夫/だいじょうぶ]だよ。' trans='是能治好的病，所以没关系的。' />
5. <grammer-content sentence='この[冷蔵庫/れいぞうこ]は[大/おお]きいからたくさん**入る**。' trans='这个冰箱很大，能装很多。' />
6. <grammer-content sentence='[私/わたし]は**[電話/でんわ]が／をかけられない**（我打不了电话）。' trans='（对比：自主动词的可能态）' />
7. <grammer-content sentence='[電話/でんわ]が**かからない**（电话打不通）。' trans='（非自主动词表示可能意义）' />
8. <grammer-content sentence='[電話/でんわ]が**かからない**。' trans='电话打不通。' />

:::

::: tip :bookmark: 补充说明

<grammer-content sentence='「電話をかけない」表示不打电话；「電話が／をかけられない」表示由于能力或条件限制而不能打；「電話がかからない」表示电话打不通，着眼于事情未能实现。' />

:::
