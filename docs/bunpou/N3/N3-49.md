# Nったら＜評価の対象＞ <Badge type="warning" text="N3" />

* 意义：在口语中把某人作为感叹或评价的对象，可表达轻微的不满、亲昵的责备或自嘲。也可以在「ったら」处停住，让语气表达态度。
* 接续：名词＋ったら
* 译文：说到……；那个……

::: info :books: 例句

1. <grammer-content sentence='[彼/かれ]**ったら**、また[遅刻/ちこく]した。' trans='说到他，又迟到了。' />
2. <grammer-content sentence='お[母/かあ]さん**ったら**、[心配/しんぱい]しすぎだよ。' trans='说到妈妈，太担心了。' />
3. <grammer-content sentence='[妹/いもうと]**ったら**、[私/わたし]の[日記/にっき]を[読/よ]んだの。' trans='说到妹妹，看了我的日记。' />
4. <grammer-content sentence='[田中/たなか]**ったら**！' trans='说到田中！（表示不满）' />
5. <grammer-content sentence='[私/わたし]**ったら**また[寝坊/ねぼう]しちゃった。' trans='我也真是的，又睡过头了。' />
6. <grammer-content sentence='もう、[李/り]さん**ったら**。' trans='哎呀，小李你真是的。' />

:::
