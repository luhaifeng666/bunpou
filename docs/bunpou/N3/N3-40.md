# ～けれども＜単純接続＞ <Badge type="warning" text="N3" />

## 引出话题或背景

* 意义：连接不具有转折意义的前后句，有时前面的分句可以起到提出话题的作用。
* 接续：句子＋けれども
* 译文：一般不必单独译出，可用“说到……”或停顿来引出后文。

::: tip :bookmark: 说明

<grammer-content sentence='「けれども」可以先交代背景，再引出请求、提问或叙述。口语中也常用「けれど」「けど」。' />

:::

::: info :books: 例句

1. <grammer-content sentence='[明日/あした][都合/つごう]がいいです**けれども**、[何/なに]かありますか。' trans='明天方便，有什么事吗？' />
2. <grammer-content sentence='[歴史/れきし]がご[専攻/せんこう]ということです**けれども**、[主に/おもに]どのような[時代/じだい]のことについて[研究/けんきゅう]されているのでしょうか。' trans='听说您专攻历史，想请问您主要研究哪个时期？' />
3. <grammer-content sentence='[私/わたし]は[今年/ことし][20歳/はたち]になるんです**けれども**、[先生/せんせい]は[20歳/はたち]の[頃/ごろ]どんな[学生/がくせい]でしたか。' trans='我今年就要满二十岁了。老师，您二十岁时是怎样的学生呢？' />
4. <grammer-content sentence='この[間/あいだ][初めて/はじめて][中国/ちゅうごく]の[結婚式/けっこんしき]に[出た/でた]んです**けれども**、[日本/にほん]の[結婚式/けっこんしき]に[対する/たいする][人々/ひとびと]の[感覚/かんかく]と[全く/まったく][違う/ちがう]ので、とても[驚き/おどろき]ました。' trans='前阵子我第一次参加中国的婚礼，发现人们对婚礼的看法和日本完全不同，很吃惊。' />

:::

## 转折用法（对照）

<grammer-content sentence='前后内容形成对照时，「けれども」也可以表示转折，相当于“虽然……但是……”。' />

::: info :books: 例句

1. <grammer-content sentence='[中村/なかむら]さんは[男/おとこ]の[人/ひと]です**けれども**、[女性/じょせい]のような[話/はな]し[方/かた]をします。' trans='中村先生虽然是男性，但说话方式像女性。' />
2. <grammer-content sentence='[日本語/にほんご]は[面白/おもしろ]いです**けれども**、[難/むずか]しいです。' trans='日语很有趣，但很难。' />

:::
