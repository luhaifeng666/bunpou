# ～なり＜二者选一＞ <Badge type="warning" text="N3" />

* 意义：表示从二者中选择一个（通常可供选择的对象不仅限于这两个事物）。
* 接续：名词／动词的辞典形＋なり
* 译文：……或者……

::: info :books: 例句

1. <grammer-content sentence='[困/こま]ったときは、[親/おや]に[相談/そうだん]する**なり**、[友達/ともだち]に[相談/そうだん]する**なり**してください。' trans='遇到困难的时候，请找父母商量或者找朋友商量。' />
2. <grammer-content sentence='[暇/ひま]なときは、[本/ほん]を[読/よ]む**なり**、[音楽/おんがく]を[聞/き]く**なり**してください。' trans='空闲的时候，请看书或者听音乐。' />
3. <grammer-content sentence='[電話/でんわ]をかける**なり**、メールを[送/おく]る**なり**して、[連絡/れんらく]してください。' trans='请打电话或者发邮件联系。' />
4. <grammer-content sentence='そういう[服装/ふくそう]についた[泥/どろ]や[埃/ほこり]は、[目で/めで][見て/みて]すぐにわかるので、その[泥/どろ]や[埃/ほこり]を**はらうなり**、また[雑巾/ぞうきん]で[拭き/ふき][取る/とる]こともできます。' trans='这类衣服上沾了泥土或灰尘，一眼就能看出来，可以掸掉，也可以用抹布擦掉。' />
5. <grammer-content sentence='[今/いま]の[仕事/しごと]を**[続け/つづけ]るなりやめるなり**、[早く/はやく][決め/きめ]なければならない。' trans='现在的工作，是继续做还是辞掉，必须尽快决定。' />
6. <grammer-content sentence='**[飛行機/ひこうき]なり[新幹線/しんかんせん]なり**、[好き/すき]な[方/ほう]で[行って/いって]ください。' trans='飞机或新干线，请选自己喜欢的方式前往。' />
7. <grammer-content sentence='そんな[問題/もんだい]なら、**[先生/せんせい]なり[友達/ともだち]なり**に[相談/そうだん]してみたらいい。' trans='那样的问题，可以试着找老师或朋友商量。' />
8. <grammer-content sentence='[熱/ねつ]があるなら、**[病院/びょういん]に[行く/いく]なり**すればよかったのに。' trans='既然发烧了，当时就该去医院看看之类的。' />

:::
