# ～ものか＜否定＞ <Badge type="warning" text="N3" />

* 意义：用反问的形式表达强烈的否定、反驳或拒绝。
* 接续：动词、形容词连体形＋ものか
* 译文：谁会……啊；不会……

::: tip :bookmark: 説明

「ものか」多用于口语，表示说话人强烈的否定或拒绝。口语中常说「もんか」，也可以用「もんですか」作较客气的反驳。

:::

::: info :books: 例句

1. <grammer-content sentence='そんなことできる**ものか**。' trans='谁能做那样的事啊。' />
2. <grammer-content sentence='[彼/かれ]の[言葉/ことば]を[信/しん]じる**ものか**。' trans='我才不会相信他的话呢。' />
3. <grammer-content sentence='[こんな/こんな][仕事/しごと]、[続/つづ]ける**ものか**。' trans='这样的工作，我才不会继续做呢。' />
4. <grammer-content sentence='[絶対/ぜったい]に[負/ま]ける**ものか**。' trans='绝对不会输。' />
5. <grammer-content sentence='[誰/だれ]がそんな[馬鹿/ばか]なことをする**もんか**。' trans='谁会做那么蠢的事啊。' />
6. <grammer-content sentence='お[客/きゃく]さんの[服/ふく]にコーヒーをこぼすような[店/みせ]には[二度/にど]と**[行く/いく]ものか**。' trans='那种把咖啡洒到客人衣服上的店，我再也不去了。' />
7. <grammer-content sentence='あの[人/ひと]にもう[二度/にど]と**[頼む/たのむ]もんか**。' trans='我再也不会去求那个人了。' />
8. <grammer-content sentence='[私/わたし]の[字が/じが]きれいだって。**きれいなもんですか**。あなたのほうがずっときれいだし。' trans='你说我的字好看？哪有啊，你的字才好看多了。' />

:::
