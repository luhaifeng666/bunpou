# ～さえ～ば<充分条件> <Badge type="warning" text="N3" />

* 意义：表示只要满足该条件，就可以得出后面的结论。
* 接续：名词+さえ+动词、形容词的条件形
* 译文：只要……就……

::: tip :bookmark: 説明

接续：①Nさえ+V/Aば ②V第一连用+さえ+すれば ③Vて（状态性）+さえ+いれば ④A1く/A2で+さえ+あれば

:::

::: info :books: 例句

1. <grammer-content sentence='[日本語/にほんご]**さえ[使/つか]えれば**[バイト代/ばいとだい]は[安/やす]くてもいいんです。' trans='只要会日语，兼职费便宜点也没关系。' />
2. <grammer-content sentence='[雨/あめ]**さえ[降/ふ]らなければ**[少/すこ]し[寒/さむ]くても[出/で]かけよう。' trans='只要不下雨，就算有点冷也出门吧。' />
3. <grammer-content sentence='いやあ、まあ、[やる気/やるき]**さえあれば**、[国籍/こくせき]にはこだわりませんよ。' trans='嗯，只要有干劲，我并不在意是哪国人。' />
4. <grammer-content sentence='**[一所懸命/いっしょうけんめい][勉強/べんきょう]さえすれば**[試験/しけん]に[合格/ごうかく]できる[だろう/だろう]。' trans='只要拼命学习，就能通过考试吧。' />
5. <grammer-content sentence='[見た目/みため]がよくなくても、[味/あじ]**さえよければ**[買い/かい]たい。' trans='即使外观不怎么样，只要味道好，我就想买。' />
6. <grammer-content sentence='ここで[待っ/まっ]**てさえいれば**いい。' trans='只要在这里等着就行。' />
7. <grammer-content sentence='[交通/こうつう]が[便利/べんり]**でさえあれば**いい。[家賃/やちん]が[少々/しょうしょう][高く/たかく]てもかまわない。' trans='只要交通方便就好。房租稍微贵一点也没关系。' />

:::

::: tip :bookmark: 补充说明

<grammer-content sentence='「Vてさえいれば」强调只要维持某个状态就足够。形容词本身也可作条件，如「安くさえあれば」「便利でさえあれば」。' />

:::
