# Vてからでないと＜必要条件＞ <Badge type="warning" text="N3" />

- 意义：表示进行后项动作之前必须先完成的事情，后项通常是否定、禁止或表示无法进行的内容。
- 接续：动词的て形＋からでないと／からでなければ。
- 译文：如果不先……就不能……；只有先……才能……。

::: tip :bookmark: 说明

「～てからでないと」和「～てからでなければ」意思基本相同，都强调前项是后项得以进行的必要条件。

在意思明确的会话中，可以省略「～てからでないと」后面的部分，委婉地表示暂时无法答应或作出决定。下面第一句中的「スケジュール帳を見てからでないと」就省略了“无法决定能不能去”等后续内容。

:::
