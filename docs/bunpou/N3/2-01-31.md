# 使动态与使动句 <Badge type="warning" text="N3" />

- <grammer-content sentence='意义：表示让对方做某事，可以是强制、许可或放任，也可表示使对方产生某种感情。' />
- 接续：动词词干后面接后缀「（さ）せる」
- 译文：使；让

::: info :books: 说明

动词类别变化规则

- <grammer-content sentence='Ⅰ类动词：将词尾的う段假名改成相应的あ段假名，再加「せる」。如「[書/か]く → [書/か]かせる」。以「う」结尾时改为「わ」，如「[言/い]う → [言/い]わせる」。' />
- <grammer-content sentence='Ⅱ类动词：去掉词尾「る」，再加「させる」。如「[見/み]る → [見/み]させる」。' />
- <grammer-content sentence='Ⅲ类动词：「[来/く]る → [来/こ]させる」「する → させる」。' />

:::

### a. 他动词使动句

<grammer-content sentence='实际做动作的人用格助词「に」标记。原主动句中由「を」标记的对象不变。' />

::: info :books: 例句

1. <grammer-content sentence='母は[子供/こども]に[本/ほん]を**[読/よ]ませる**。' trans='妈妈让孩子读书。' />
2. <grammer-content sentence='[先生/せんせい]は[学生/がくせい]に[日本語/にほんご]を**[話/はな]させる**。' trans='老师让学生说日语。' />
3. <grammer-content sentence='[娘/むすめ]が[日本/にほん]から[帰国/きこく]するとき、いつも1か[月/げつ][前/まえ]から**[予約/よやく]させてる**の。' trans='女儿从日本回国的时候，我总是让她提前一个月左右订票。' />

:::

### b. 自动词使动句

动作的主体一般用「を格」表示，有时也可以用「に格」表示。

::: info :books: 例句

1. <grammer-content sentence='[親/おや]は[子供/こども]を[買い物/かいもの]に**[行か/いか]せる**。' trans='父母让孩子去买东西。' />
2. <grammer-content sentence='[次/つぎ]は僕に**やらせて**ください。' trans='下一次请让我来做。' />
3. <grammer-content sentence='[子供/こども]をあんなところへ**[行か/いか]せる**のは[心配/しんぱい]です。' trans='让孩子去那种地方，真让人担心。' />

:::

::: tip :bookmark: 补充说明

<grammer-content sentence='不考虑动作主体的意愿、特别是表示强迫时，通常使用「を」；考虑其意愿，表示允许其做某事时，则常使用「に」。' />

:::

### c. 使动句的含义

1. 命令、强制对方做某事
2. 许可、放任对方做某事
3. 引发对方产生某种感情（动作的主体只能用"を格"表示）

::: info :books: 例句

1. <grammer-content sentence='先生が学生に[日本語/にほんご]で[作文/さくぶん]を**[書/か]かせる**。' trans='老师让学生用日语写作文。' />
2. <grammer-content sentence='先生は学生に[自由/じゆう]に[発表/はっぴょう]テーマを**[選/えら]ばせた**。' trans='老师让学生自由选择发表主题。' />
3. <grammer-content sentence='先生はいつも[冗談/じょうだん]を[言/い]ってみんなを**[笑/わら]わせる**。' trans='老师总是开玩笑让大家笑。' />
4. <grammer-content sentence='お[母さん/かあさん]は[子供/こども]たちを[早く/はやく]**[寝さ/ねさ]せた**。' trans='妈妈让孩子们早点睡觉。' />
5. <grammer-content sentence='[子供/こども]に[長時間/ちょうじかん]ゲームを**させて**はいけません。' trans='不能让孩子长时间玩游戏。' />
6. <grammer-content sentence='[失礼/しつれい]なことを[言って/いって]しまって、[先輩/せんぱい]を**[怒/おこ]らせた**。' trans='我说了失礼的话，惹前辈生气了。' />

:::

## 使动与授受表达

::: info :books: 例句

1. <grammer-content sentence='[具合/ぐあい]が[悪か/わるか]ったので、ちょっと[早く/はやく]**[帰ら/かえら]せてもらいました**。' trans='因为身体不舒服，我获准稍微早一点回去了。' />
2. <grammer-content sentence='[親/おや]が[一生懸命/いっしょうけんめい][働い/はたらい]て、[私/わたし]を[大学/だいがく]に**[行か/いか]せてくれた**。' trans='父母辛勤工作，供我上了大学。' />
3. <grammer-content sentence='いい[大学/だいがく]に[入/はい]って[親/おや]を**[喜ば/よろこば]せてあげたい**。' trans='我想考上一所好大学，让父母高兴。' />
4. <grammer-content sentence='それでは、[発表/はっぴょう]を**[始め/はじめ]させていただきます**。' trans='那么，请允许我开始发表。' />
5. <grammer-content sentence='[風邪/かぜ]を[引い/ひい]たので、[今日/きょう][1日/いちにち]**[休ま/やすま]せてください**。' trans='我感冒了，请允许我今天休息一天。' />

:::

::: tip :bookmark: 补充说明

<grammer-content sentence='「V（さ）せる」后接「てもらう／いただく」「てくれる／くださる」「てあげる／さしあげる」等，可以结合使动与授受关系，表达得到许可或某人为自己创造条件等意思。' />

:::
