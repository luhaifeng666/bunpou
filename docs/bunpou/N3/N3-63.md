# ～Vかける<动作的阶段> <Badge type="warning" text="N3" />

* 意义：表示某动作刚刚开始或正在进行中尚未完成。也可以用「VかけのN」的形式。
* 接续：动词第一连用形+かける
* 译文：开始……；……了一半

::: info :books: 例句

1. <grammer-content sentence='そう[思って/おもって]、「スケジュール[帳/ちょう]を[見て/みて]からでないと」と**[言い/いい]かけたら**、「よかったら、[母さん/かあさん]と[一緒に/いっしょに]」とさっさとチケットを[2枚/にまい][渡さ/わたさ]れた。' trans='我这么想着，刚要说“得先看看日程本”，对方就麻利地递来两张票，说“可以的话，就和妈妈一起去吧”。' />
2. <grammer-content sentence='**[手紙/てがみ]を[書き/かき]かけたところ**に、[電話/でんわ]がかかってきた。' trans='刚开始写信，电话就打来了。' />
3. <grammer-content sentence='**[読み/よみ]かけの[小説/しょうせつ]**を[友達/ともだち]に[持っ/もっ]て[行か/いか]れた。' trans='没读完的小说被朋友拿走了。' />
4. <grammer-content sentence='[彼は/かれは]**[飲み/のみ]かけたコーヒー**をテーブルに[置いた/おいた]まま、どこかへ[行って/いって]しまいました。' trans='他把没喝完的咖啡留在桌上，不知去了哪里。' />
5. <grammer-content sentence='[中谷/なかたに]さんは[交差点/こうさてん]で[車/くるま]に**ぶつかりかけた**。' trans='中谷差点在十字路口撞上汽车。' />

:::

::: tip :bookmark: 补充说明

<grammer-content sentence='「VかけたN」和「VかけのN」都可以修饰名词，如「飲みかけたコーヒー」「飲みかけのコーヒー」。“差一点……”也可用「Vかける」表达，如「ぶつかりかけた」。' />

:::
