# ～っぽい<性质、倾向> <Badge type="warning" text="N3" />

* 意义：接名词时表示带有某种性质或给人类似的感觉。接动词时，表示容易出现某种行为或反应。
* 接续：名词/动词第一连用形+っぽい
* 译文：有……倾向的；动不动就……；容易……

::: info :books: 例句

1. <grammer-content sentence='でも、アニメのような**[子供/こども]っぽい**[映画/えいが]の[話/はなし]など[聞い/きい]ても、どうせつまらないだろう……。' trans='不过，就算听人讲起动画那样孩子气的电影，想必也没什么意思吧……' />
2. <grammer-content sentence='[一/いち][ヶ月/かげつ]も[留守/るす]にしていたので、[家/いえ]の[中/なか]が**[埃/ほこ]っぽい**。' trans='因为离开了一个月，家里都是灰。' />
3. <grammer-content sentence='**[忘/わす]れっぽい**[人/ひと]は[不便/ふべん]だ。' trans='健忘的人不方便。' />
4. <grammer-content sentence='[彼/かれ]は**[怒/おこ]りっぽい**[人/ひと]です。' trans='他是容易发火的人。' />
5. <grammer-content sentence='[若い/わかい][社長/しゃちょう]が「[世界一/せかいいち]の[会社/かいしゃ]にしたい」という[夢/ゆめ]を、**[熱っ/あつっ]ぽく**[語り/かたり]ました。' trans='年轻的总经理热情地讲述了想把公司办成世界第一的梦想。' />
6. <grammer-content sentence='[彼は/かれは][疲れ/つかれ]ると、**[怒/おこ]りっぽく**なる。' trans='他一累就容易发脾气。' />

:::
