# ～ふりをする＜假装＞ <Badge type="warning" text="N3" />

- 意义：表示实际上并非如此，却故意装出某种样子。
- 接续：动词、Ⅰ类形容词的连体形＋ふりをする；Ⅱ类形容词词干＋な＋ふりをする；名词＋の＋ふりをする。
- 译文：假装……；装作……。

::: tip :bookmark: 说明

<grammer-content sentence='口语中可以省略「を」，说成「ふりする」。课件也写作片假名「フリ」；这里统一为「ふり」。' />

<grammer-content sentence='动词的た形表示假装已经做过某事，ない形表示假装不知道、没做等，并非只能接这两种形式。' />

:::

::: info :books: 例句

1. <grammer-content sentence='[彼女/かのじょ]に[会っ/あっ]たとき、[知ら/しら]ない**ふりをして**[通り/とおり][過ぎ/すぎ]た。' trans='遇到她的时候，我装作不认识她，从她身旁走了过去。' />
2. <grammer-content sentence='[試験/しけん]の[結果/けっか]を[聞か/きか]れたけど、[忘れ/わすれ]た**ふりをして**[答え/こたえ]なかった。' trans='被问到考试结果时，我装作忘记了，没有回答。' />
3. <grammer-content sentence='[友達/ともだち]がサプライズで[私/わたし]に[誕生日/たんじょうび]プレゼントを[渡し/わたし]たので、[驚い/おどろい]た**ふりをして**[喜んだ/よろこんだ]。' trans='朋友把生日礼物当作惊喜送给我，于是我装作很惊讶的样子，表现得很高兴。' />
4. <grammer-content sentence='[孤独/こどく]な**ふりをしてる**の？' trans='你是在装作很孤独的样子吗？' />
:::
