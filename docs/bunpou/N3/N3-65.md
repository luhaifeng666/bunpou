# ～Vたとたん（に）<契机出现> <Badge type="warning" text="N3" />

* 意义：表示某一动作或变化刚一发生，紧接着就出现了后句所述的动作或变化。后句多含有出乎意料的含义。
* 接续：Vた+とたん（に）
* 译文：一……就……；刚……就……

2. <grammer-content sentence='**テレビをつけたとたん**、[停電/ていでん]になってしまった。' trans='一打开电视，就停电了。' />

4. <grammer-content sentence='**[窓/まど]を[開/あ]けたとたん**、[小鳥/ことり]が[飛/と]び[込/こ]んできた。' trans='一打开窗户，小鸟就飞进来了。' />
