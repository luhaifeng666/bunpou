# ～ないことはない<双重否定> <Badge type="warning" text="N3" />

- <grammer-content sentence="意义：用双重否定表示带有保留的肯定。常先承认某种可能或事实，再说明限制或顾虑。" />
- <grammer-content sentence="接续：**动词、形容词的否定形**＋ことはない" />
- 译文：也并非不……；倒也不是不能……

::: tip :bookmark: 説明

也可以用「ないこともない」的形式，语气更为委婉。

:::

::: info :books: 例句

1. <grammer-content sentence="A：**これ、まだ[食/た]べられる？**" trans="A：这个，还能吃吗？" />
   <grammer-content sentence='B：う〜ん、[食べ/たべ]られ**ないことはない**けど、[賞味期限/しょうみきげん]が[切れ/きれ]ているのでやめておいたほうがいいと[思う/おもう]よ。' trans='B：嗯，也不是不能吃，不过已经过了最佳食用期，我觉得还是别吃了。' />

2. <grammer-content sentence='でき**ないことはない**かもしれないけど。' trans='也许并非做不到，只是……' />

3. <grammer-content sentence='[納豆/なっとう]は[食べ/たべ]**ないことはない**んですけど、あまり[好き/すき]ではありません。' trans='纳豆倒也不是不吃，只是不太喜欢。' />

4. <grammer-content sentence="[提出/ていしゅつ]は[明日/あした]は[無理/むり]ですが、[明後日/あさって]までなら、[出来/でき]**ないことはない**。" trans="明天交不行，但后天之前也不是做不到。" />

5. <grammer-content sentence='A：**[林/りん]さん、[彼女/かのじょ]のこと、ほんとは[好き/すき]じゃないんじゃないの？**' trans='A：林同学，你其实并不喜欢她吧？' />
   <grammer-content sentence="B：う〜ん、[好/す]きじゃ**ないことはない**んだけど……。" trans="B：嗯，也不是不喜欢……" />
6. <grammer-content sentence='おいしく**ないことはない**んですが、ちょっと[味/あじ]が[薄い/うすい]ような[気が/きが]しました。' trans='也不是不好吃，只是我觉得味道有点淡。' />

:::
