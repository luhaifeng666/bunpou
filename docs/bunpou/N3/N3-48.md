# ～もの＜强調原因・理由＞ <Badge type="warning" text="N3" />

* 意义：表示原因、理由。
* 接续：简体句子＋もの
* 译文：因为……嘛

::: tip :bookmark: 説明

常用于非正式会话，说明原因、为自己辩解，或强调自己的感受。口语中常说「もん」，也常与句首的「だって」呼应。

:::

::: info :books: 例句

1. <grammer-content sentence='A：[遅/おそ]かったですね。B：[道/みち]が[込/こ]んでた**もの**。' trans='A：好晚啊。B：因为路上很堵嘛。' />
2. <grammer-content sentence='[子供/こども]は[寝/ね]る[時間/じかん]だ**もの**、[早/はや]く[寝/ね]なさい。' trans='因为孩子该睡觉了嘛，快睡吧。' />
3. <grammer-content sentence='[私/わたし]は[子供/こども]じゃない**もの**。' trans='因为人家不是孩子嘛。' />
4. <grammer-content sentence='[私たち/わたしたち]は[初対面/しょたいめん]だ**もん**、ちょっとはずかしい。' trans='毕竟我们第一次见面嘛，有点不好意思。' />
5. <grammer-content sentence='[李/り]さんのためだ**もの**、きっとやってくれるよ。' trans='因为是为了小李嘛，他肯定会帮忙的。' />
6. <grammer-content sentence='[新人/しんじん]です**もん**。[頑張ら/がんばら]なくちゃ。' trans='因为我是新人嘛，得加把劲。' />
7. <grammer-content sentence='だって、お[腹/なか]すいちゃったんだ**もん**。' trans='因为我肚子饿了嘛。' />

:::
