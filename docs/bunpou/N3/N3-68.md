# ～だけあって<成正比的因果关系> <Badge type="warning" text="N3" />

* 意义：表示前后句所述的情况相符合、成正比。常与副词「さすがに」呼应使用。
* 接续：名词/动词、形容词的连体形+だけあって
* 译文：不愧是……；正因为……

::: info :books: 例句

1. <grammer-content sentence='**[黒沢/くろざわ][監督/かんとく]の[講演/こうえん]というだけあって**、[場内/じょうない]は[満員/まんいん]だ。' trans='不愧是黑泽导演的演讲，现场座无虚席。' />
2. <grammer-content sentence='**[日本/にほん]に20[年/ねん]もいただけあって**、[日本/にほん]のことに**[詳/くわ]しい**。' trans='不愧是在日本待了20年，对日本的事情非常了解。' />
3. <grammer-content sentence='**[若/わか]いだけあって**、[回復/かいふく]が[早/はや]かった。' trans='正因为年轻，恢复得很快。' />
4. <grammer-content sentence='[京華/きょうか][大学/だいがく]の[学生/がくせい]**だけあって**、いろいろな[方面/ほうめん]で[優/すぐ]れた[才能/さいのう]を[持っ/もっ]ている。' trans='不愧是京华大学的学生，在各方面都有出众的才能。' />
5. <grammer-content sentence='[新しい/あたらしい][監督/かんとく]は[指導/しどう][経験/けいけん]が[豊富/ほうふ]な**だけあって**、[選手/せんしゅ]の[気持ち/きもち]をコントロールするのがうまい。' trans='新教练不愧有丰富的执教经验，很擅长调动选手的情绪。' />

:::
